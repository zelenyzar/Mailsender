```markdown
# Домашняя работа

## Содержание:
1. Настроен проект Django с приложением Mailing
2. Добавлены модели Client, Message, Mailing, MailingAttempt
3. Реализованы CRUD-операции для клиентов, сообщений и рассылок
4. Настроена кастомная модель пользователя (user.User)
5. Добавлена функция регистрации и подтверждения почты
6. Ограничен функционал для незарегистрированных пользователей
7. Добавлены группы пользователей и назначены права (менеджер)
8. Реализованы кастомные команды: create_manager, create_fixture, send_mailing
9. Добавлена панель управления и страница статистики рассылок
10. Настроено серверное и клиентское кеширование (Redis)

## Установка:
1. Клонируйте репозиторий:
(`git clone`) [GitHub] (https://github.com/zelenyzar/Django22.1)
2. Установите зависимости:
(`pip install -r requirements.txt`)
3. Создайте файл .env и заполните переменные окружения
(секретный ключ, данные PostgreSQL, настройки SMTP)
4. Примените миграции:
(`python manage.py migrate`)
5. Загрузите тестовые данные:
(`python manage.py loaddata mailing/fixtures/test_data.json`)
6. Запустите сервер:
(`python manage.py runserver`)

## Использование проекта:
1. Откройте проект в браузере по адресу http://127.0.0.1:8000;
2. Зарегистрируйтесь и подтвердите почту;
3. Создайте получателей (клиентов) и шаблоны сообщений;
4. Создайте рассылку, укажите период и получателей;
5. Запустите рассылку вручную или через команду
(`python manage.py send_mailing <pk>`);
6. Просмотрите статистику отправок на странице /statistics/.
```

Пара замечаний, чтобы README точно прошёл проверку:

- **В «Содержании» пиши только то, что реально сделано.** Если, например, групп пользователей нет — убери пункт 7, иначе ревьюер проверит и вернёт на доработку.
- **Пункт про кеширование сформулирован как «серверное и клиентское»** — это совпадает с формулировкой задания №10. Убедись, что в коде есть и Redis/`cache.set` (серверное), и `cache_page` или заголовки `Cache-Control` (клиентское) — обычно требуют именно оба.
- Если у тебя нумерация в чек-листе отличается (1–9 из предыдущих уроков + 10 кеширование) — просто перенумеруй пункты под свои реально выполненные этапы, структура останется той же.
